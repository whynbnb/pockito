# Utility Kit

一个面向 Android、iOS、Windows、macOS 和 Linux 的本地隐私笔记应用原型。应用启动后显示密码生成器，连续长按顶部的 `Password Generator` 标题进入私密区域。

## 当前功能

- 密码生成器：8 到 64 位，可分别筛选小写、大写、数字和特殊字符。
- 特殊需求：唯一字符、排除易混淆字符，均可独立开启；唯一字符默认关闭。
- 自定义种子：支持输入文字，也支持采集鼠标移动和触摸 / 手势轨迹。
- 结果操作：一键复制、字符类型彩色高亮、恢复初始设置。
- 桌面宽屏下筛选项采用双列布局，窄屏自动切换为单列布局。
- 外层生成器、解锁页和内层笔记共享主题与语言设置，支持浅色 / 深色、跟随系统主题、English / 中文和跟随系统语言，并会保存到系统安全存储。
- 隐藏入口：长按首页标题。
- 首次使用创建主密码，并生成一次性显示的恢复密钥。
- 使用主密码、恢复密钥或系统生物识别 / Windows Hello 解锁。
- 私密笔记支持标题、文字和图片附件。
- 数据保存在应用支持目录下的单个 `utility-cache.pvlt` 文件中。

## 存储和安全边界

库文件不是 SQLite，而是自定义版本化 envelope。笔记 payload 使用 AES-256-GCM 加密，主密码通过 PBKDF2-HMAC-SHA256（210,000 次迭代）派生密钥。数据密钥本身使用密码槽位和恢复密钥槽位分别封装；生物识别解锁时，数据密钥存放在系统安全存储中。

写入先完成 `.writing` 文件并 flush，再将旧文件移到 `.backup`，最后替换主文件。启动时会识别并恢复有效的中断文件，之后清理临时文件。该机制覆盖应用崩溃和大多数进程中断场景，但不能替代文件系统、磁盘或硬件损坏时的备份策略。

## 重要限制

这是可运行的基础版本，不应直接作为经过安全审计的密码管理器发布。当前“类 UKey”入口使用离线恢复密钥作为跨平台恢复因子；真正的 FIDO2 / U2F 硬件密钥需要分别接入 Android、Apple 和桌面端原生 API，并需要设计挑战响应、设备注册、密钥轮换和恢复流程。Linux 的生物识别能力取决于系统和插件实现，主密码 / 恢复密钥是通用路径。

## 运行

```bash
flutter pub get
flutter run -d macos
```

使用 `flutter devices` 查看已配置的 Android、iOS、Windows、macOS 和 Linux 设备。Web 平台没有加入工程目标。
